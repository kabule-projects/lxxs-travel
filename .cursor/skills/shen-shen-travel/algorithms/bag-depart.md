# 背包出行算法

背包为弹窗（黑色遮罩），非独立页面。槽位见设计稿：

```
美食 food ×1：必填，type=food
米字星 rice ×1：选填，点击直接填充（有库存/收藏即可）；V1 标记 usedRiceStar，默认不扣数量
道具 prop ×2：选填，type=accessory|equipment；影响目的地权重与明信片偏向
```

## 选物列表（第二层弹窗）

```
也是「所拥有物品」展示栏
带 Tab：美食 / 道具
从背包某槽打开时：锁定对应 Tab，只能选该类
点条目 → 写入该槽；已装入的槽右上角红叉可卸下
```

## 出发流程（变更）

```
准备 → 填背包 → 出发 → 居中提示框「小深出门旅行了」
（无告别确认小窗、无鸽子过场）

点「出发」：无美食 → toast「需要准备食物」
有美食 → 关背包 → trip/start → CHARACTER_HIDDEN → 主页显示旅行提示条
旅行中再次点准备/背包 → toast 同文案
```

服务端：校验库存 ≥1；扣美食与道具各 1；米字星仅打标；`trip.status = traveling`
