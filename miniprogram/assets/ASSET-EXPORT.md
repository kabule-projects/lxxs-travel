# 旅行小深 · WebP 作图导出规范

> 给美术 / 设计：怎么画、怎么导出、怎么命名、怎么交图。  
> **文件名逐条对照表** → [`ASSET-NAMING.md`](./ASSET-NAMING.md)  
> **代码登记源** → `miniprogram/utils/asset-path.ts`

---

## 1. 为什么有 @2x 和 @3x

手机屏幕像素密度不同，同一逻辑尺寸需要不同物理像素：

| 后缀 | 含义 | 典型设备 |
|------|------|----------|
| `@3x` | 3 倍图 | iPhone 17 Pro Max 等（本项目设计基准） |
| `@2x` | 2 倍图 | 多数高端安卓、部分 iPhone |

代码会按机型自动选档：优先对应 DPR，找不到再回退另一档或无后缀 `.webp`。

**每个资源必须导出两套文件**，否则部分机型发糊或走占位。

---

## 2. 设计基准（固定）

| 项 | 值 |
|----|-----|
| 基准机型 | iPhone 17 Pro Max |
| 逻辑分辨率 | 440 × 956 pt |
| **@3x 画布** | **1320 × 2868 px** |
| **@2x 画布** | **880 × 1912 px**（整页 = @3x × 2/3） |
| 格式 | **仅 WebP**（禁止业务资源用 PNG / JPG） |
| 质量建议 | 80–85 |
| 色彩 | sRGB |

**作图习惯：** 始终在 **1320 × 2868** 的 @3x 稿上画；需要 @2x 时再整体缩到 **66.67%（×2/3）**。

---

## 3. 两类资源怎么导

### 3.1 整页背景（BG）

适用：`home/room`、`shared/roof/bg`、`shop/page-bg` 等。

| 档位 | 尺寸 | 透明 |
|------|------|------|
| @3x | 1320 × 2868 | 可不透明 |
| @2x | 880 × 1912 | 可不透明 |

**禁止画进背景的内容（代码会另叠一层）：**

- 顶栏星星 / 米字星数字与货币条
- 底栏「准备」、商店、扭蛋、回小屋等按钮
- 设置网格、背包、返回等导航 icon
- 屋顶可收集星星、鸽子（若代码单独叠图则以代码为准）

背景只放「不动的场景」：房间家具、夜空屋顶、商店装潢等。

### 3.2 按钮 / icon / 弹窗零件（UI）

1. 在 @3x 稿里按**实际显示大小**画在**透明底**上  
2. **裁切到元素边缘**（可留少量安全边）  
3. 导出两份：
   - `@3x`：原尺寸  
   - `@2x`：宽高各 × **2/3**

| 类型 | @3x 参考边长（约） | @2x |
|------|-------------------|-----|
| 小 icon（设置、背包等） | 72–120 px 宽 | ×2/3 |
| 中按钮（商店、回小屋等） | 96–160 px | ×2/3 |
| 大按钮（`btn-prepare`） | 按设计稿实际宽度 | ×2/3 |
| 弹窗面板 | 按设计稿实际尺寸 | ×2/3 |

**不要**把小 icon 画在整张 1320 宽的画布上再导出——程序用 `rpx` 控制显示大小。

## 4. 导出参数

| 项 | 设置 |
|----|------|
| 格式 | WebP |
| 质量 | 80–85 |
| 透明 | 按钮、icon、星星、鸽子、弹窗零件 → **保留 Alpha** |
| 整页背景 | 可不透明 |
| 命名 | 与 [`ASSET-NAMING.md`](./ASSET-NAMING.md) **一字不差** |

每个资源最终两个文件：

```
{路径}@3x.webp
{路径}@2x.webp
```

放到：

```
miniprogram/assets/{路径}@3x.webp
miniprogram/assets/{路径}@2x.webp
```

示例：

```
miniprogram/assets/icons/home/star@3x.webp
miniprogram/assets/icons/home/star@2x.webp
miniprogram/assets/home/room@3x.webp
miniprogram/assets/home/room@2x.webp
```

## 5. 推荐工作流

### Figma

1. Frame：**1320 × 2868**（@3x 主稿）  
2. 整页背景 → Export WebP（1320 宽）→ 重命名为 `{路径}@3x.webp`  
3. 同一内容缩放到 **66.67%** → Export → `{路径}@2x.webp`  
4. 每个按钮 / icon 单独 Component → 分别导出 @3x 与 @2x（或插件批量）  
5. 按 [`ASSET-NAMING.md`](./ASSET-NAMING.md) 路径放入 `miniprogram/assets/`

### Photoshop

1. 文档 **1320 × 2868** 作图  
2. 「存储为 WebP」→ `@3x`  
3. 「图像大小」宽高改为 **66.67%** → 再存一份 → `@2x`  
4. 小元素：先裁切选区，再按上两步各存一份

## 6. 分层原则（避免 UI 一塌糊涂）

| 类型 | 谁画 | 注意 |
|------|------|------|
| 静态整页底图 BG | 美术一整张 | 不要含 HUD / 按钮 |
| 场景装饰 DECO | 美术 | 代码用 CSS 定位 |
| 可点击 UI | 美术透明图 | 尺寸由代码 `nav-icon` / wxss 控制 |
| 弹窗面板 MODAL | 美术框体 | 动态文字（版本号、用户 ID）前端画 |
| 游戏动态 GAME | 程序 / 云配置 | 星星坐标、商品 icon、明信片缩略图 |

**常见翻车：**

| 错误 | 结果 |
|------|------|
| BG 里画了「准备」按钮，又交了 `btn-prepare` | 双重按钮 |
| BG 里画了星星数量 | 与顶栏数字重叠 |
| 只出 `@3x` 或路径大小写不对 | 加载失败 / 占位 |
| 用 wxml 内联 `style` 修图位置 | 换图必崩，应改 wxss |

## 7. 交图检查清单

```
[ ] 每个资源都有 @2x 和 @3x
[ ] 全部是 .webp（无 .png / .jpg）
[ ] 文件名与 ASSET-NAMING.md 完全一致（路径、连字符、大小写）
[ ] 已放入 miniprogram/assets/ 对应子目录
[ ] 整页 BG 不含顶栏货币、底栏按钮、设置网格
[ ] icon / 按钮为透明底，未铺满 1320 整屏
[ ] 弹窗面板不含动态文案（用户 ID、版本号等）
[ ] 真机预览：无双重按钮、无明显错位
```

## 8. 临时只出一档时

开发联调可以**暂时只出 `@3x`**，代码会回退尝试；正式适配与发包前请补齐 `@2x`。

不要只交无后缀的 `xxx.webp` 代替两档（可作为最后兜底，但不推荐作为正式交付）。
