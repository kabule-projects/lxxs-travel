| `icons/home/bag@3x.webp` | 顶栏背包 |
| `icons/home/shop@3x.webp` | 底栏商店 |
| `icons/shop/utility-gacha@3x.webp` | 底栏扭蛋 |
| `icons/common/settings-grid@3x.webp` | 顶栏设置（网格） |
